# 新版 60 日概念導向課程

這版已把原本相近的「理解日」與「比較與應用日」合併。

## 學習安排

- Day 1-30：初級完整複習，每天一個考試概念。
- Day 31-60：中級入門到應考教材，涵蓋中級三科。
- 每日教材皆包含：核心概念、名詞解釋、類比、實務應用流程、考試比較題方向、今日練習。

## 建議讀法

1. 先看 [60 日教材總表](./02_60日概念導向計畫.md)。
2. 再讀 [60 日完整每日教材](./01_30類核心教材.md)，或直接用 `web-reader/index.html` 按 Day 閱讀。
3. 讀完後用今日練習做 10 分鐘輸出。
4. 每週回官方公告試題檢查：錯題屬於定義、比較、流程、風險還是案例。

新手工程師提醒：不要把 AI 考試當純背誦。比較有效的方法是把每個名詞放回「資料從哪裡來、模型/工具做什麼、誰負責、怎麼驗收、有哪些風險」這條線。
