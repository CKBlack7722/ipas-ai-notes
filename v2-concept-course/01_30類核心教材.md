# Day 01：AI、ML、DL、GenAI 層級

等級：初級
科目/範圍：人工智慧基礎概論

## 今日學習目標
今天要把「AI、ML、DL、GenAI 層級」讀到可以做單選題的程度：看到題幹能判斷它是在問定義、比較、流程、風險或案例。工程師新手可以先抓關鍵字，再把它放回實務流程，不需要一開始就背所有術語。

## 核心概念與名詞解釋
- AI 是讓機器表現智慧任務的總稱。
- ML 是從資料學規律。
- DL 是多層神經網路形式的 ML。
- GenAI 是能產生文字、圖片、程式等新內容的 AI。

## 類比理解
AI 像百貨公司，ML、DL、GenAI 是不同樓層或櫃位。

## 實務上怎麼用
### 應用 1：企業客服知識庫問答
流程：
1. 盤點 FAQ、產品手冊與客服紀錄。
2. 清理重複與過期答案。
3. 設定回答來源與人工覆核規則。
4. 用小範圍客戶問題做 PoC。
5. 追蹤答覆正確率、平均處理時間與升級人工比例。
關鍵處：重點不是讓 AI 自由聊天，而是讓它依據可信資料回答。

### 應用 2：製造瑕疵檢測
流程：
1. 定義瑕疵類型與允收標準。
2. 蒐集正常與異常影像。
3. 標註資料並切分訓練/驗證/測試集。
4. 選擇影像分類或物件偵測模型。
5. 上線後監控誤判、漏判與產線環境變化。
關鍵處：影像資料代表性比模型名稱更重要，光線、角度、相機位置都會影響結果。

### 應用 3：行銷內容生成與審稿
流程：
1. 建立品牌語氣、禁用詞與合規清單。
2. 用 Prompt 產生多版文案。
3. 由行銷與法務審核。
4. A/B 測試不同版本。
5. 回收點擊率、轉換率與客訴作為改版依據。
關鍵處：生成式 AI 適合產生初稿，但對外發布前必須有人審。

## 考試比較題方向
常拿 AI、ML、DL、GenAI 的包含關係互相比較；不要把 GenAI 當成所有 AI。

答題時請用「需求 -> 資料 -> 方法/工具 -> 風險 -> 指標」檢查選項。若選項只強調技術很新，卻沒有處理資料、風險或導入流程，通常不是最佳答案。

3. 選一個上面的實務應用，寫出資料來源、AI 類型、主要風險與 KPI。

科目/範圍：生成式 AI 導入評估規劃

## 今日學習目標
今天要把「KPI、ROI、TCO 與效益衡量」讀到可以做單選題的程度：看到題幹能判斷它是在問定義、比較、流程、風險或案例。工程師新手可以先抓關鍵字，再把它放回實務流程，不需要一開始就背所有術語。

## 核心概念與名詞解釋
- KPI 是成功指標。
- ROI 是投資回報。
- TCO 是全生命週期總成本。
- 效益可包含節省時間、降低錯誤、提升滿意度。
- 成本包含授權、雲端、整合、維護、訓練與風險。

## 類比理解
買車不只看車價，也要看油錢、保養與保險。

## 實務上怎麼用
### 應用 1：企業客服知識庫問答
流程：
1. 盤點 FAQ、產品手冊與客服紀錄。
2. 清理重複與過期答案。
3. 設定回答來源與人工覆核規則。
4. 用小範圍客戶問題做 PoC。
5. 追蹤答覆正確率、平均處理時間與升級人工比例。
關鍵處：重點不是讓 AI 自由聊天，而是讓它依據可信資料回答。

### 應用 2：製造瑕疵檢測
流程：
1. 定義瑕疵類型與允收標準。
2. 蒐集正常與異常影像。
3. 標註資料並切分訓練/驗證/測試集。
4. 選擇影像分類或物件偵測模型。
5. 上線後監控誤判、漏判與產線環境變化。
關鍵處：影像資料代表性比模型名稱更重要，光線、角度、相機位置都會影響結果。

### 應用 3：行銷內容生成與審稿
流程：
1. 建立品牌語氣、禁用詞與合規清單。
2. 用 Prompt 產生多版文案。
3. 由行銷與法務審核。
4. A/B 測試不同版本。
5. 回收點擊率、轉換率與客訴作為改版依據。
關鍵處：生成式 AI 適合產生初稿，但對外發布前必須有人審。

## 考試比較題方向
便宜工具不一定低 TCO；KPI 不等於 ROI。

答題時請用「需求 -> 資料 -> 方法/工具 -> 風險 -> 指標」檢查選項。若選項只強調技術很新，卻沒有處理資料、風險或導入流程，通常不是最佳答案。

1. 用自己的話寫出本日 3 個名詞解釋。
2. 為每個名詞補一個生活例子。
3. 選一個上面的實務應用，寫出資料來源、AI 類型、主要風險與 KPI。
4. 自出 2 題單選題，並解釋錯誤選項為什麼錯。
