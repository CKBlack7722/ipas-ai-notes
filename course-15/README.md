# iPAS 中級科目一、科目二：15 日衝刺講義

本版取代閱讀器的 60 日課程入口，僅聚焦中級「人工智慧技術應用與規劃」及「大數據處理分析與應用」。每天約一小時，共約 15 小時；先理解任務與限制，再記名詞與公式。原 60 日網頁教材資料備份於 `../archive/60-day-reader/notes-data.js`，既有獨立筆記保留供參考。

每天講義都有必備名詞、白話類比、實務例子、可能出題方向、測驗解析與閉卷檢核。出題方向依公開評鑑主題設計，不是必考保證，也沒有把未取得的命題頻率當成統計。

## 每天一小時

5 分鐘回想 → 30 分鐘讀講義 → 15 分鐘算例與測驗 → 10 分鐘閉卷復述、記錯因。Day 15 改為整合與弱點回補。若概念不清，優先補讀對應官方章節，不必把所有影片看完才開始做題。

## 使用與維護

- 開啟專案網頁入口 index.html：主教材資料夾位於 web-reader，GitHub 發布版位於根目錄；不需伺服器或 API 金鑰。
- `daily-notes/DAY01.txt` 至 `DAY15.txt`：可獨立閱讀的 UTF-8 文字檔。
- `course-data.json`：結構化教材，包含 day、subject、subjectNumber、codes、topic、text，方便 AI Agent 依科目及代碼擷取。
- `course-source.js`：可維護的教材來源。
- `node build-course.cjs --sample`：先產一日樣稿到 sample。
- `node build-course.cjs`：檢查 15 日並產出文字、JSON 與閱讀器資料。

原本六份模擬考與 Agent 實作仍可使用。舊模擬考包含初級及中級科目三概念，不是這次雙科專用考卷；本講義內共 32 題附解析練習可用於雙科複習。
