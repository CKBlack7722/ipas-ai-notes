# AI Agent 實作專區

本專區用「iPAS 備考助教 Agent」作為範例，把 AI Agent 的概念對應到 iPAS AI 應用規劃師考點，並提供一個免 API、可本機開啟的互動模擬版。

## 建議閱讀順序

1. `01_AI_Agent_考點總覽.md`：先看 Agent 是什麼，以及它和 Chatbot、RAG、Workflow、AutoML 的差異。
2. `02_AI_Agent_實作筆記.md`：照著流程理解「目標輸入 -> 任務拆解 -> 知識檢索 -> 答案生成 -> 風險檢查 -> KPI 評估」。
3. `03_AI_Agent_考題比較表.md`：用單選題角度記住常見比較與陷阱。
4. `web-reader/index.html`：打開網頁版，切到「AI Agent 實作」操作一次。

## 對應 iPAS 考點

- 初級：人工智慧基礎概論、資料處理與分析、機器學習概念、鑑別式 AI 與生成式 AI、No Code / Low Code、生成式 AI 導入評估與風險管理。
- 中級：人工智慧技術應用與規劃、大數據處理分析與應用、機器學習技術與應用、系統集成與部署、模型治理。

## 學習心法

把 Agent 想成「會照目標做事的專案助理」。LLM 像它的大腦之一，RAG 像它翻資料的能力，工具呼叫像它能打開不同系統處理任務，治理像它的工作規範與安全邊界。
